go-ruby-zlib is a pure-Go (no cgo) reimplementation of Ruby's Zlib standard library — the MRI Zlib module — built entirely on the Go standard library (compress/zlib, compress/flate, compress/gzip, hash/crc32, hash/adler32). It offers deflate / inflate, gzip, the byte-exact CRC-32 and Adler-32 checksums (and their combine forms), and a streaming compressor / decompressor, so a host such as go-embedded-ruby can serve require "zlib" with no C extension and a static, CGO=0 binary. It is a standalone, reusable module with no dependency on the Ruby runtime — a sibling of go-ruby-regexp, go-ruby-yaml and go-ruby-erb.

A faithful port of Ruby's Zlib module in pure Go, cgo disabled, built on the Go standard library's compress/* and hash/* packages. The CRC-32 and Adler-32 checksums (and their combine forms) are byte-exact with MRI; the deflate / gzip / streaming paths round-trip and interoperate with MRI in both directions. Validated by a differential oracle against the system ruby binary. It is a standalone, reusable module — the zlib backend for the sibling org github.com/go-embedded-ruby.
